# Figma dumps
เก็บ dump ใหม่เป็นโฟลเดอร์ตาม file key และวันที่ พร้อม source.json ระบุ fileKey, capturedAt, dumpVersion และเครื่องมือที่ใช้
ไม่ถือว่าชื่อเหมือนกันเป็น component เดียวกัน ต้องตรวจ published key และ properties กับ mapping
ยังไม่ได้คัดลอก dump เก่า 176 MB มาปะปนกับ dump ใหม่ที่เจ้าของงานกำลังเตรียม
