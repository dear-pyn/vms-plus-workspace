# แบบตารางรายการ — อ้างอิงจากเว็บเก่า VMS Plus

ตรวจวันที่ 13 พฤศจิกายน 2569 จากหน้า [นัดหมายบำรุงรักษา](https://vmsplus-dev.pea.co.th/maintenance-management/maintenance-schedule) (เว็บเก่า ต้องต่อ VPN และล็อกอิน) เจ้าของงานกำหนดว่า "พวกตาราง เราจะใช้ประมาณนี้"

สถานะ: **reference จากระบบเดิม ยังไม่ใช่แบบที่ลูกค้ายืนยัน** ค่าที่จะใช้จริงต้องเทียบกับ component `Table` / `Badge` / `Pagination` / `Side panel` ใน Figma dump (`design/figma-dump/`) ก่อนเสมอ ถ้าเว็บเก่ากับ Figma ขัดกัน ให้ยึด Figma แล้วจดไว้ในหัวข้อ "จุดที่ต้องเทียบ"

## โครงหน้า (บนลงล่าง)

1. Breadcrumb: ไอคอนบ้าน > ชื่อหน้า
2. หัวข้อหน้า (ขนาดใหญ่)
3. แถบเครื่องมือ
   - ซ้าย: ช่องค้นหา placeholder "เลขที่การนัดหมาย, เลขทะเบียน" (ค้นด้วยเลขเอกสารและเลขทะเบียน)
   - ขวา: ปุ่มรอง "ตัวกรอง" พร้อมตัวเลขจำนวนตัวกรองที่ใช้อยู่ (เริ่มต้น 0) และปุ่มหลัก "เพิ่มนัดหมายใหม่" พร้อมไอคอน
4. ตาราง
5. แถบแบ่งหน้า

## แบ่งหน้า

ซ้าย "แสดง 1 ถึง 10 จาก 77 รายการ" · ตัวเลือกจำนวนต่อหน้า (ค่าเริ่มต้น 10) · ขวา ปุ่มก่อนหน้า 1 2 3 … 8 ถัดไป

## ตัวกรอง

เปิดเป็น panel ด้านขวา (side panel) หัว: ไอคอน + "ตัวกรอง" + คำอธิบาย "กรองข้อมูลให้แสดงเฉพาะข้อมูลที่ต้องการ" + ปุ่มปิด

| ฟิลด์ | ชนิด |
|---|---|
| สังกัดยานพาหนะ | dropdown ค้นหาได้ ค่าเริ่มต้น "ทั้งหมด" |
| วันที่นัดหมาย | เลือกช่วงวันที่ placeholder "ระบุช่วงวันที่นัดหมาย" |
| ประเภทการบำรุงรักษา | checkbox หลายตัว: ตรวจสอบสภาพทั่วไป, บำรุงรักษาตามรอบ, ซ่อมแซมกรณีรถเสีย |
| สถานะการนัดหมาย | checkbox ที่ label เป็น badge: รอดำเนินการ, เสร็จสิ้น, ยกเลิก |

ท้าย panel: ลิงก์ "ล้างตัวกรอง" (ซ้าย) · ปุ่ม "ยกเลิก" (รอง) · ปุ่ม "ตกลง" (หลัก)

## จุดที่ต้องเทียบกับ Figma ก่อนใช้

- รูปแบบวันที่: เว็บเก่าใช้ปี ค.ศ. (25/12/2025) ต้นแบบของเราใช้ พ.ศ. ต้องยืนยันว่าใช้แบบไหน
- badge 2 แบบในตารางเดียว (มีจุดสี vs สีเต็ม) ตรงกับ variant ไหนของ `Badge` ในไลบรารี
- คอลัมน์ action ควร fix ติดขวาเมื่อเลื่อนแนวนอนหรือไม่ (เว็บเก่าไม่ fix)
- จำนวนต่อหน้าที่เลือกได้ (เห็นแค่ค่าเริ่มต้น 10)
- ปุ่มหลักต้องการสิทธิ์ตาม role หรือไม่ (ตรวจด้วยบัญชีเดียว)
