# Scene B (S1 สร้างแผน Overhaul) — Senior review + ต้นแบบ r1

**ต้นแบบ:** `/prototypes/overhaul/#/new` · ทำแล้ว B.1–B.19 (ทางเลือก modal) · B.20–B.23 ทางเลือกเต็มหน้า **ไม่ทำ** (เคาะ D1)
จำลอง B.5: ตั้งชื่อแผนให้มีคำว่า "error" · ฟอร์มเดียวกันใช้กับ S2 แก้ไขแผน (ได้โครง 2 คอลัมน์ตาม Figma ไปด้วย)
ข้อความแจ้งผลเปลี่ยนเป็น `Notification` การ์ดขาวมุมขวาบน ตามจอ B.18 C.5 D.3 (เดิมทำเป็น Toast สีเข้ม — ผิด component)
ต้นแบบเติมเอง (รอยืนยัน): validation เอกสารบังคับ "กรุณาแนบหนังสืออนุมัติหลักการ / เอกสารอนุมัติงบ" (AC-S1 บอกว่าบังคับ แต่จอไม่มีข้อความ) ·
หัวข้อ modal ราคา "ระบุราคารายคัน" (จอเขียน "แก้ไขข้อมูลผู้ใช้ยานพาหนะ") · คำว่า "รถ" → "ยานพาหนะ" ทั้งฟอร์ม

แหล่ง: จอ Figma B.1–B.23 (dump figma-overhaul-refinement-09) · FigJam refinement (โน้ตเรื่องเลือกรถ/ราคา) · AC-S1 (15-overhaul-AC.md)
skill: senior-ux-review + senior-dev-review · สถานะทุกข้อ = pending จนกว่าเจ้าของงานตอบ

## เคาะแล้ว (เจ้าของงาน 13 พ.ย. 2569)
- **D1 = Modal** (B.15–B.18) ตามที่คุยกันไว้ · ไม่ใช้ทางเลือก B เต็มหน้า → ต้องปิดช่องโหว่การเลือกจำนวนมากในหัวข้อ "เลือกยานพาหนะจำนวนมากใน modal"
- **D2 = ตารางเดียว** เลือกใน modal แล้วแสดงในฟอร์มเป็นตาราง **เหมือนตารางยานพาหนะ A.5** (ทะเบียน/สังกัด · ยี่ห้อ รุ่น/ประเภท · มูลค่า · ราคากลาง · ประเมิน Overhaul · อายุ · ความคืบหน้า)
- **D3 = เมนู "…"**: ดูข้อมูลยานพาหนะ · ดูข้อมูลการซ่อม · ระบุราคา · ลบยานพาหนะ (สีแดง)

## จุดผิดในจอ Figma ที่ต้องแก้ (ไม่ใช่เคส แต่เจอระหว่างรีวิว)
- modal ราคารายคัน (B.10 B.11 B.13) หัวข้อเขียน **"แก้ไขข้อมูลผู้ใช้ยานพาหนะ"** — ก๊อปมาจากจออื่น ควรเป็น "ระบุราคารายคัน"
- ช่องค้นหาเขียนไม่ตรงกัน 3 แบบ: modal "ทะเบียน, ยี่ห้อ/รุ่น, ประเภท, สังกัด" · เต็มหน้า "ทะเบียน, รุ่น, สังกัด" · FigJam (แท็บยานพาหนะ) "ทะเบียน, ยี่ห้อ/รุ่น ไม่เอาสังกัด"
- คำว่า "รถ" ยังมีทั้งจอ — FigJam: "รถ → ยานพาหนะ นับแต่บัดนี้"
- B.7 รายละเอียดแผน "จำนวนรถที่ Overhaul 0 คัน" แต่ "รถในแผน (2 คัน)"
- AC-S1 ยังไม่มีเรื่องเลือกรถ/ราคารายคันเลย (เพิ่มมาใน Figma รอบหลัง) — AC ต้องอัปเดต

การเผยแพร่หรือแก้ AC ไม่เปลี่ยน requirement ที่อนุมัติแล้วโดยอัตโนมัติ ดู วิธีทำงาน
