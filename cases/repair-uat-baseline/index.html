# งานซ่อม (แจ้งซ่อม) · ต้นแบบเทียบ UAT r2

**เวอร์ชัน (23 พ.ย. 2569):** `main` = **ตาม UAT 100%** (ตั้งต้น · ไม่มี flow ที่ต้นแบบเติม) · branch `repair-v2` = **ปรับตาม feedback 1** (ทุกอย่างในหัวข้อ 2 เป็นต้นไป และบันทึกการยืนยัน r2–r7)

ต้นแบบ: `/prototypes/repair/` · ดูระบบจริง: vms-plus-uat.odds.team/maintain-d/repair-utility-vehicle (20 พ.ย. 2569 · ตัวตนทดสอบ "นาย กบค" admin-super)
ข้อมูลในต้นแบบเป็นค่าสมมติทั้งหมด · ป้ายม่วงเส้นประ **"เพิ่มใหม่ · รอยืนยัน"** = จอ/ทางที่ UAT ยังไม่มี

## 1. สิ่งที่ทำตาม UAT (observed)

| จอ | สิ่งที่ตรงกับ UAT |
|---|---|
| รายการ | คอลัมน์ 8 + ปุ่มดู · ค้นหา "หมายเลขเหตุการณ์, เลขทะเบียน" · เรียงคอลัมน์ · แบ่งหน้า 10/25/50/100 · ว่าง "ไม่มีรายการแจ้งซ่อม" · สีป้ายสถานะ (warning / brand "รอตรวจสภาพก่อนซ่อม" / success "ซ่อมเสร็จ" / gray "ปิดงาน") |
| ตัวกรอง | สถานะเหตุการณ์ 24 ค่าเรียงตาม API · ยี่ห้อรถ · ประเภทรถ · สถานะรถ · วันนัดหมาย · ล้างตัวกรอง / ยกเลิก / ตกลง |
| แจ้งซ่อม 4 ขั้น | กล่องสรุปยานพาหนะ · "ส่วนที่ต้องการแจ้งซ่อม" เฉพาะรถกระเช้า/เครน · เอกสารแนบเฉพาะ "ซ่อมศูนย์บริการ/อู่" · ช่องตามงบ 5 แบบ · tooltip ผู้รับแจ้งเหตุ · อาการเสียเลือกหลายค่า · อะไหล่ 2 แผง · หน้ายืนยัน · กล่อง "ยืนยันการส่งอนุมัติ" · การ์ดส่งเรื่องสำเร็จ · กล่อง "ออกจากหน้านี้" |
| รอหัวหน้าหน่วยงานอนุมัติ | เลือกวิธีซ่อม 2 การ์ด · ส่งคืนงานซ่อม (เหตุผล) · รับงานซ่อม → "ส่งอนุมัติเพื่อเปิดงานซ่อม" (ผู้อนุมัติ) |
| รอหัวหน้า กบค. อนุมัติ | เลือกวิธีซ่อม · ส่งคืนงานซ่อม · อนุมัติ |
| กระบวนการซ่อม 7 ขั้น | ขั้น 1–2 แบบล็อก · ขั้น 3 เอกสารรับรถ 13 ข้อ + ลงนาม + ตรวจสภาพ 24 ข้อ · ขั้น 4 พบ/ไม่พบอาการเพิ่ม + เบิก/ไม่เบิกอะไหล่ · ขั้น 5 นัดคืนรถ + "รอตอบกลับจากหน่วยงาน" · ขั้น 6 ตรวจหลังซ่อม + คะแนน 1–5 + จำนวนที่ใช้/คืน · ขั้น 7 เอกสาร + อะไหล่เก่า + เอกสารปิดงาน 15 ข้อ · ส่งอนุมัติ / อนุมัติปิดงาน |
| แท็บ | ประวัติการซ่อม (ค้นหาอาการเสีย · ตัวกรอง · รายงาน (n)) · ประวัติการดำเนินการ |
| เมนู | "รายการแจ้งซ่อม" · "สร้างใบแจ้งซ่อม" ใต้ จัดการยานพาหนะขนาดใหญ่ |

**เวอร์ชันตาม UAT ทำเหมือน UAT ทุกจุดที่เห็นได้** — สิ่งที่ UAT ไม่บอกผล: ส่งคืนงานซ่อมแล้วไปสถานะไหน (ต้นแบบใช้ "ไม่อนุมัติ") · อนุมัติแบบอู่ภายนอกแล้วไปไหน (ต้นแบบใช้ "รอตรวจสภาพก่อนซ่อม" เหมือนซ่อมโดย กบค.)

**ต่างจาก UAT โดยตั้งใจ:** เงินแสดง `0.00 บาท` ตาม MONEY-001 (UAT `0 บาท`) · ขนาดหัวหน้าใช้ PageHeader ของไลบรารี (32px) · ผลค้นหาอะไหล่ฝั่งซ้ายเป็นแบบของต้นแบบ เพราะ UAT ค้นแล้วไม่พบรายการเสมอ · ปุ่ม "แก้ไขนัดหมาย" กดได้ (UAT ดูเหมือนปิดไว้)

## 2. จุดที่ UAT ข้ามขั้น (r2 · 23 พ.ย. 2569)

| # | UAT ข้ามอะไร | หลักฐาน (observed) | ต้นแบบ r2 ทำอะไร |
|---|---|---|---|
| S1 | หัวหน้าหน่วยงานไม่มีหน้าอนุมัติของตัวเอง · ข้ามงานคัดแยก กรย. และ กบค รับเรื่อง/พิจารณา | หน้า "รอหัวหน้าหน่วยงานอนุมัติ" มีปุ่ม "รับงานซ่อม" ของ กบค. · ไม่มีงานในสถานะ กรย./กบค รับเรื่อง | เมนู **อนุมัติงานซ่อม** + หน้า กรย. คัดแยก 3 ทาง + กบค รับเรื่อง (F2, F3) |
| S2 | อนุมัติแล้วกระโดดไป "รอตรวจสภาพก่อนซ่อม" — ข้ามเตรียมอะไหล่และส่งนัดหมาย | ขั้น 1–2 ล็อกเสมอ · ไม่มีงานใน "เตรียมอะไหล่" / "รอต้นทางยืนยันนัดหมาย" | ขั้น 1 เลือก+ยืนยันเบิกอะไหล่ · ขั้น 2 ส่งนัดหมาย (F5, F6) |
| S3 | หน่วยงานต้นทางไม่ได้ตอบนัดหมายเอง | ปุ่ม "ต้นทางยืนยัน" ให้ กบค. กดแทน เปลี่ยนสถานะทันที | เมนู **ตอบรับนัดหมายงานซ่อม** (ตอบรับในช่วงวันที่ กบค. เสนอ / ปฏิเสธ + เหตุผล + วันที่สะดวก) · ปุ่มลัดเหลือเฉพาะ admin-super |
| S4 | ผู้ส่งมอบรถ (หน่วยงาน) ไม่ได้เซ็นเอง | ปุ่ม "เซ็นลงนาม" ทั้งสองฝั่งอยู่ในหน้า กบค. | ฝั่งหน่วยงาน "ส่งให้เซ็นลงนาม" → หน่วยงานเซ็นจากเมนูตอบรับ · ยืนยันขั้นได้เมื่อเซ็นครบ |
| S5 | ไม่มีการบันทึกระหว่างซ่อม | ขั้น 4 มีแค่ผลอาการเพิ่ม | **บันทึกความคืบหน้า** (วันเวลาอัตโนมัติ · % · หมายเหตุ) แบบ Overhaul |
| S6 | เจออาการเพิ่มไม่มีคนอนุมัติ | สถานะ "เจออาการเพิ่ม" มีใน API · กล่อง "ส่งอนุมัติเพื่อเปิดงานซ่อม" ซ่อนอยู่ | หน้าอนุมัติอาการเพิ่มของหัวหน้า กบค. (F7) |
| S7 | ต้นทางปฏิเสธวันคืนรถไม่ได้ | สถานะ "รอ กบค. ส่งนัดหมายวันคืนรถใหม่อีกครั้ง" ไม่มีทางไปถึง | ปฏิเสธจากเมนูตอบรับ → กบค. ส่งนัดใหม่ (F8) |
| S8 | ปิดงานไม่มีผู้อนุมัติเฉพาะ / ส่งกลับแก้ไขไม่ได้ | ปุ่ม "อนุมัติปิดงาน" อยู่ในหน้าเดียวกับคนส่ง | อนุมัติจากเมนูอนุมัติงานซ่อม + ส่งกลับแก้ไข (F9) |
| S9 | งานอู่ภายนอก/ซ่อมเองไม่มีการติดตาม | งานปิดแล้วไม่มีแท็บกระบวนการซ่อม | ฟอร์มบันทึกผลการซ่อม → ปิดงาน (F4) |
| S10 | ไม่มีแจ้งเตือน | กระดิ่งว่าง | แจ้งเตือนตาม role ทุกจุดส่งต่องาน (กดแล้วไปหน้าที่ต้องทำ) |
| S11 | ปิดงานทันทีใช้ไม่ได้ | ปุ่มปิด "ยังไม่พร้อมใช้งาน" | เปิด + บังคับเหตุผล (F10) |

เทียบกับ Overhaul และมติ 23 พ.ย. 2569 ดู [repair-vs-overhaul.md](repair-vs-overhaul.md) · r3: เมนู "ตอบรับนัดหมาย" / "อนุมัติงาน" รวมกับ Overhaul แบ่งแท็บตามประเภท

## 2.1 รายการ flow ที่เติม (F1–F11) และคำถาม

API มี 24 สถานะ แต่ UAT มีจอ/งานจริงแค่ 10 สถานะ

| # | สถานะ / จุด | ต้นแบบทำอะไร | คำถามถึง กฟภ. |
|---|---|---|---|
| F1 | ส่งคืนงานซ่อม → ? | กล่องส่งคืนเพิ่มตัวเลือก "ส่งกลับต้นทางซ่อมเอง" / "ไม่อนุมัติ" | ส่งคืนแล้วไปสถานะไหน (ก) ส่งกลับซ่อมเอง (ข) ไม่อนุมัติ (ค) แล้วแต่ผู้อนุมัติเลือก |
| F2 | รอ กรย พิจารณา · กรย เห็นชอบ ซ่อมเอง · รอ กรย ดำเนินการ | หน้า "พิจารณางานคัดแยก (กรย.)" 3 ปุ่ม | หน้าส่งเรื่องบอก "อนุมัติแล้วไป งานคัดแยก กรย." แต่ปุ่มใน UAT ไปหัวหน้า กบค. — ลำดับที่ถูกคืออะไร |
| F3 | รอ กบค รับเรื่อง · รอ กบค พิจารณา | ปุ่ม "รับเรื่อง" แล้วเลือกวิธีซ่อมเหมือนหน้าอนุมัติ | สองสถานะนี้ต่างกันอย่างไร |
| F4 | ส่งกลับต้นทางซ่อมเอง · ดำเนินการซ่อมเอง · อนุมัติแบบอู่ภายนอก | ต้นทางรับทราบ → ฟอร์ม "บันทึกผลการซ่อม" (อู่ · วันที่เสร็จ · ค่าใช้จ่าย · เลขไมล์ · ไฟล์) → ปิดงาน | งานอู่ภายนอก/ซ่อมเองต้องบันทึกอะไรก่อนปิด · ต้องมีผู้อนุมัติไหม |
| F5 | เตรียมอะไหล่ (ขั้น 1 แก้ได้) | เลือกอะไหล่ ตั้งต้นจากที่ผู้แจ้งเลือก · ยืนยันเบิก / ไม่เบิกอะไหล่ | ใครยืนยันเบิก · ต้องอนุมัติใบเบิกไหม |
| F6 | ขั้น 2 ส่งนัดหมาย · รอต้นทางยืนยันนัดหมาย | ฟอร์มส่งนัด → หน้ารอ → ต้นทางยืนยัน / ขอเปลี่ยนวัน (เหตุผล) | ต้นทางตอบผ่านหน้าไหน (เมนูของหน่วยงาน หรือแจ้งเตือน) |
| F7 | เจออาการเพิ่ม | UAT มีกล่องส่งอนุมัติซ่อนอยู่ → หน้าอนุมัติ/ไม่อนุมัติของหัวหน้า กบค. · อนุมัติแล้วรวมอะไหล่เพิ่ม | ไม่อนุมัติแล้วซ่อมต่อหรือหยุดงาน |
| F8 | รอ กบค. ส่งนัดหมายวันคืนรถใหม่อีกครั้ง | ต้นทางขอเปลี่ยนวันคืนรถ → กบค. ส่งนัดใหม่ | — |
| F9 | ไม่อนุมัติปิดงาน | "ส่งกลับแก้ไข" พร้อมเหตุผล → กลับไปขั้น 7 | ต้องมีทางไม่อนุมัติไหม |
| F10 | ปิดงานทันที | UAT ปิดปุ่ม ("ยังไม่พร้อมใช้งาน") → ต้นแบบเปิด + บังคับเหตุผล | ใครกดได้ · ขั้นไหนกดได้ |
| F11 | รอต้นทางรับรถกลับไปใช้งาน · รอ คนแจ้งซ่อม ยืนยันนัดหมาย วันคืนรถ | ยังไม่ทำ (แสดงป้ายเท่านั้น) | ใช้ตอนไหน — UAT หลังต้นทางยืนยันรับรถไป "ตรวจสภาพหลังซ่อม" ทันที |

## 5. ข้อสังเกตระหว่างดู UAT

- ปุ่ม "ต้นทางยืนยัน" (ขั้น 5) เปลี่ยนสถานะทันทีเมื่อกด — ระหว่างดูหน้า กดปุ่มนี้ 1 ครั้ง งานทดสอบ RRB6900015 จึงเปลี่ยนจาก "รอต้นทางยืนยันรับรถ" เป็น "รอ กบค. ตรวจสภาพหลังซ่อม" บน UAT
- งานที่ปิดแล้วแบบอู่ภายนอกไม่มีแท็บกระบวนการซ่อม

การเผยแพร่หรือแก้ AC ไม่เปลี่ยน requirement ที่อนุมัติแล้วโดยอัตโนมัติ ดู วิธีทำงาน
