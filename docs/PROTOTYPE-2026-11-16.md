## แก้ appointment sync — 16 พ.ย. 2569

- ย้าย state แผน/Purchase Order/งานรายคันไป `prototype/usePrototypeData.ts` ที่เก็บ snapshot localStorage key `vms-plus:overhaul-prototype:v1` (เฉพาะต้นแบบ ไม่อยู่ใน packages/ui)

- JobPage ติดตามสถานะงานเมื่อเลือกขั้น: คำตอบจากอีกแท็บเปลี่ยน code แล้วเปิดขั้นถัดไปให้; ยังคงเลือกดูขั้นเก่าได้
