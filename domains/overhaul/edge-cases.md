# Overhaul — ทะเบียนเคสประหลาด (Edge cases)

ใช้ร่วมทุก scene ของ Overhaul · senior-ux-review / senior-dev-review ต้องเช็คทะเบียนนี้ก่อนรีวิว scene ใหม่ และเพิ่มเคสที่เจอใหม่ต่อท้าย (รหัส EC ไม่ใช้ซ้ำ)
สถานะ: **pending** = รอลูกค้าตอบ (ต้นแบบใช้วิธีที่แนะนำ + ป้าย "รอยืนยัน") · **confirmed** = ลูกค้ายืนยันแล้ว (ใส่ผู้ยืนยัน/วันที่) · **done** = ทำในต้นแบบแล้ว
